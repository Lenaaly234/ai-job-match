# AI Job Match

AI Job Match is an AI-powered CV-to-job-description analysis tool built with Next.js and Gemini.

Users upload a PDF CV, paste a job description, and receive a structured report showing:

- Match score
- Match level
- Matching skills
- Skill gaps
- CV strengths
- AI recommendations
- Requirement-by-requirement evidence
- Required vs. preferred job requirements
- Full, partial, and missing requirement matches

## Problem

Job seekers often apply without knowing how closely their CV matches the actual requirements of a role.

AI Job Match helps users compare their CV against a job description before applying. Instead of returning only a generic AI response, the application provides structured and evidence-based feedback that explains where the candidate matches the role and where important gaps exist.
